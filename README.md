## Description
A database system to manage books, students, and borrowing records
for a school library. Designed using both MySQL (relational) and
MongoDB (NoSQL).

## Technologies Used
- MySQL
- MongoDB
- draw.io (ER Diagram)

## How to Run
1. Open /mysql/schema.sql in MySQL and run it
2. Run /mysql/queries.sql to test queries
3. Open /mongodb/collections.json for MongoDB data
